## ✦ Overview

This is the personal portfolio of **K.M. Siam**, a Computer Science & Engineering undergraduate at Southeast University (Dhaka, Bangladesh) specializing in **Machine Learning**, **Deep Learning (Computer Vision & NLP)**, and **Full-Stack Web Engineering**.

The website is engineered with a monochrome editorial aesthetic that blends brutalist minimalism with cutting-edge web graphics. It features liquid lens WebGL shaders, kinetic scroll-expanded media stages, a 3D cylindrical drum reel, and interactive modal case studies highlighting real-world production projects, capstones, and academic research.

## ✦ Quickstart & Local Setup

Clone the repository and serve locally using any static web server:

```bash
# Clone the repository
git clone https://github.com/KMSiam/My_Portfolio.git

# Navigate to directory
cd My_Portfolio

# Start a local HTTP server (Python 3)
python -m http.server 8080

# Or using Node.js
npx serve .
```

Open `http://localhost:8080` in any modern web browser.
